DMART DATA ANALYST ASSIGNMENT – SUBMISSION PACKAGE
==================================================

Candidate deliverables for the Preliminary Round.

CONTENTS
--------
1. Dmart_Analysis_Report.xlsx
   - Main analysis workbook
   - Sheets: Executive Summary (KPIs, Data Quality, Insights, Recommendations),
     Sales by Category, Channel & Payment, Customer Insights, Monthly Trend,
     Top Products, Notes & Assumptions

2. Dmart_PowerBI_Style_Dashboard.html
   - Interactive visual dashboard (open in Chrome/Edge)
   - Pages: Executive Overview, Trends & Products, Customer Insights,
     Quality & Stores, Insights & Actions

3. Dmart_Transactions_Cleaned.csv
   - Cleaned transaction data with calculated metrics
     (Gross Sales, Discount Amount, Net Sales, COGS, Gross Profit)

4. Dmart_Customers_Cleaned.csv
   - Deduplicated and standardised customer master

5. Dmart_Products_Cleaned.csv
   - Product lookup reference

HOW TO REVIEW
-------------
- Start with Dmart_Analysis_Report.xlsx → Executive_Summary sheet
- Open the HTML dashboard in a browser for interactive visuals
- Cleaned CSVs demonstrate data validation and preparation work

ASSUMPTIONS (brief)
-------------------
- Only "Completed" transactions included in revenue/profit KPIs
- Transaction grain is product-line (not bill/order)
- Prices and costs taken from Product Lookup
- Data quality issues identified, quantified, and corrected in cleaned files
